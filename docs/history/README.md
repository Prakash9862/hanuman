## Règle d’utilisation

Une archive peut expliquer pourquoi une décision a été prise ou fournir une
preuve datée. Elle ne doit pas être utilisée pour :

- lancer l’application ;
- connaître une route actuelle ;
- annoncer un nombre courant de tests ou une couverture ;
- affirmer la disponibilité d’une fonctionnalité ;
- définir une convention encore active.

Pour cela, revenir à [l’index documentaire](../README.md).
