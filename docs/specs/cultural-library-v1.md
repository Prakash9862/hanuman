# Bibliothèque culturelle fédérée — Spécification V1

## Intention utilisateur

Chercher une œuvre, un compositeur, un interprète ou un sujet dans plusieurs
sources, sélectionner les résultats pertinents et constituer une fiche
personnelle durable.

## Sources interrogées en V1

- IMSLP ;
- Gallica ;
- YouTube ;
- Wikipédia si disponible ;
- liens ou notes Obsidian sélectionnés explicitement.

## Destination choisie pour V1

Notion devient le catalogue principal.

Obsidian reste l’espace d’analyse, de rédaction et de liens intellectuels.

Hanuman conserve les relations entre la fiche Notion, les sources externes et
les éventuelles notes Obsidian.

## Pourquoi Notion pour le catalogue

- propriétés structurées ;
- vues filtrées ;
- catégories ;
- couvertures et médias ;
- consultation visuelle ;
- meilleure présentation d’une collection.

## Pourquoi Obsidian pour les notes

- Markdown local ;
- rédaction longue ;
- liens entre concepts ;
- annotations personnelles ;
- indépendance et portabilité.

## Entrée V1

Une recherche textuelle, par exemple :

« Ambroise Thomas — Hamlet ».

## Plan

Hanuman interroge les sources et normalise uniquement :

- titre ;
- type de ressource ;
- auteur ou créateur ;
- date si connue ;
- URL ;
- source ;
- court résumé ;
- provenance et date de consultation.

## Preview

L’utilisateur voit :

- les résultats regroupés par source ;
- les doublons probables ;
- les éléments déjà présents dans la bibliothèque ;
- la fiche Notion proposée ;
- les liens facultatifs vers Obsidian.

## Apply

Après sélection :

- créer ou mettre à jour une fiche Notion ;
- ajouter uniquement les ressources choisies ;
- enregistrer les URL et la provenance ;
- ne jamais copier intégralement des contenus protégés.

## Verify

- relire la page Notion créée ;
- vérifier les propriétés essentielles ;
- signaler les sources manquantes ou les écritures partielles.

## Hors périmètre V1

- aspiration exhaustive de toutes les sources ;
- index local intégral ;
- téléchargement automatique de partitions ;
- reconnaissance automatique parfaite des doublons ;
- synchronisation bidirectionnelle générale avec Obsidian ;
- génération autonome de critiques artistiques.

## Critères d’acceptation

- aucune fiche créée sans sélection humaine ;
- chaque élément possède une source ;
- les doublons sont proposés, jamais fusionnés silencieusement ;
- Notion reste le catalogue et Obsidian le laboratoire ;
- Hanuman n’essaie pas de devenir lui-même une bibliothèque propriétaire.
