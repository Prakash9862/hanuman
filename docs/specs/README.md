# Spécifications

Les fichiers de ce dossier décrivent des fonctionnalités proposées. Ils ne
constituent pas une documentation de capacités disponibles.

| Spécification | État dans le code |
|---|---|
| [Calendar + Maps + Gmail V1](calendar-maps-gmail-v1.md) | non implémentée comme orchestration ; les connecteurs de lecture existent |
| [Bibliothèque culturelle fédérée V1](cultural-library-v1.md) | recherche par source disponible ; catalogue et collecte persistante absents |

Une spécification promue en fonctionnalité doit :

1. être confrontée au code livré ;
2. devenir un contrat d’orchestration dans `docs/orchestrations/` ;
3. faire déplacer les détails opératoires vers les guides ;
4. conserver ici seulement l’historique ou être supprimée.
